# SEO da landing page

1. Definir se a landing será a página principal (`/`) ou terá uma URL própria. Usar apenas uma URL canônica.
[FEITO]
2. Configurar no `<head>`: título, meta description, canonical, robots, Open Graph e Twitter Card.
[FEITO]
3. Manter apenas um `h1` e usar `h2` para organizar as seções da página.
[FEITO]
4. Usar textos e links descritivos para destinos, categorias, posts e stories.
[FEITO]
5. Otimizar imagens com `alt`, dimensões, WebP/AVIF, `srcset` e lazy loading abaixo da primeira tela.
[FEITO]
6. Adicionar dados estruturados JSON-LD para `WebSite` e `Organization` ou `Person`.
[FEITO]
7. Incluir a landing no sitemap e confirmar que ela não está bloqueada no `robots.txt`.

8. Verificar desempenho, responsividade, status HTTP 200 e indexação no Google Search Console.
